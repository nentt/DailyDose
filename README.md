# Habit Tracker App (SwiftUI)

A personal project to build a clean, user-centric mobile application that helps users build and maintain daily habits.

This app is my hands-on laboratory for learning **SwiftUI**, **mobile product architecture**, and the **iterative development process**.

---

## 🚀 Current Status: MVP Discovery & Visual Core

I am currently working on:
- **Main Dashboard**
- **Habit Creation Flow**

The goal is to deliver a solid **MVP (Minimum Viable Product)** with a strong focus on **ease of use** and **visual clarity**.

---

## ✨ Key Features (In Development)

- **Daily Habits**  
  A central view where users can see all their habits for the day.

- **Overview**  
  A view where users can see all their progress across the month.

- **Intuitive Tracking**  
  Simple tap-to-track interactions directly from the main view.

- **Flexible Habit Creation**
  - **Quick Start**: Choose from a library of pre-defined habits.
  - **Custom Habits**: Define your own goals (e.g. *“Read 10 pages per day”*).

- **Clean UI**  
  Built entirely with SwiftUI, following native iOS design principles.
